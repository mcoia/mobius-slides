You too, can have an Evergreen server!


Step 1

Install Docker on your computer

Download here

Step 2

Browse the available Evergreen containers

https://hub.docker.com/r/mobiusoffice/evergreen-ils

Step 3

Open Powershell or Linux Command Line

docker run -it -p 80:80 -p 443:443 -p 210:210 -p 6001:6001 \
-p 32:22 -p 5433:5432 -h app.evergreen.com \
mobiusoffice/evergreen-ils:3.9.1

Step 4

Wait

Takes about 5 minutes

Step 5

Open a web browser and browse to localhost

Takes about 5 minutes

Click through SSL certificate warnings
