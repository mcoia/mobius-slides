Do you wish your SIP traffic from your library to the server were encrypted?

Do you have one of these?

Maybe it's time for a SIP proxy server

https://github.com/mcoia/evergreen_sip_proxy

Clone the repo

Customize your variables

Edit this file

16.04.yml

Refer to this file

raspberry pi installation notes.txt

You can use minimum hardware

Boot the pi up on MATE

Use the ansible script to install

cd /sip_proxy && ansible-playbook install_sip_proxy_server.yml

Install cronjob

evergreen_sip_proxy_launch.sh

Point the selfcheck machines at the pi

Forget about it

  • AutoSSH will reconnect
  • Proxy server remembers "93" login packets
  • Proxy server will re-login upon disconnection
  • It uses SSH tunnel for encryption
