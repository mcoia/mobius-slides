# MOBIUS Slides

Each folder is a presentation. The reveal.js files are not tracked. You will need to 
clone the reveal.js and propagate our presentation files in order to see the presentation as intended.

Example:

    git clone git@github.com:mcoia/mobius-slides.git
    git clone git@github.com:hakimel/reveal.js.git
    cp -R mobius-slides/blake/antora/* reveal.js/
